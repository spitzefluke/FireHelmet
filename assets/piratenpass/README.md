# Piratenpass-Assets

Das Bild der Stufe-50-Endbelohnung ("Ich bin eine Flitzpiepe"-Cap),
siehe `PIRATE_PASS_CAP_IMAGE` in `scripts/core/progression-data.js`:

```
assets/piratenpass/cap.webp
```

Falls diese Datei fehlt, zeigt die Piratenpass-Seite automatisch ein
textbasiertes Abzeichen statt eines kaputten Bild-Tags (siehe
`renderCapBadge()` in `scripts/piratenpass/piratenpass.js`) - kein
Platzhalterbild nötig.
